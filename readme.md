## 澳门六合彩开奖记录分析与预测软件 (macau_predictor)

功能: 自动读取 https://macaujc.com 历史开奖记录, 采用统计模型 + 大模型反推理,
给出下一期三组预测(6平码+1特码), 回测评估各组命中率并推荐, 罗列反推理出的数学模型。

模块结构:
  - data_fetcher.py   数据抓取/解析/缓存 (macaujc.com JSON API)
  - analysis.py       统计分析: 卡方均匀性/冷热号/遗漏值/马尔可夫/自相关/和值正态
  - llm_reasoner.py   大模型反推理 (OpenAI 兼容接口, 可降级)
  - backtest_utils.py 回测引擎: 准确率/随机基线/lift/标准误差/稳定性
  - predictor.py      三组完整预测 + 五组特码预测(均含回测)
  - dimensions.py     六维度特码属性预测 + 特码三生肖预测(单组3生肖)
  - special_pool.py   特码号码集合预测: 8~10颗(6策略) + 20颗大集合(单组多信号融合)
  - prediction_store.py 预测历史持久化 + 命中核对(保存/查阅/对照实际开奖)
  - macau_gui.py      图形界面主入口 (tkinter, 含"历史预测"页)
  - macau_predictor.py 主入口 CLI

运行方式:
  python -X utf8 macau_predictor.py [--refresh] [--years 2024,2025,2026] [--backtest 60]

参数:
  --refresh    强制重新抓取数据(否则优先用本地缓存 macau_history.json)
  --years      抓取年份, 逗号分隔, 默认 2024,2025,2026
  --backtest   回测期数, 默认 60

大模型配置: 编辑 config.ini 填入 OpenAI 兼容接口的 base_url / api_key / model
(如 DeepSeek、通义、Moonshot、OpenAI)。未配置时自动降级为纯统计模型。

预测历史保存与查阅 (GUI「历史预测」页):
  - 每次点击「开始分析」生成预测后, 完整预测数据自动存档到 prediction_history.json
    (基准期号/生成时间/三组完整/五组特码/六维度/号码集合/大集合/三生肖/反推模型)。
  - 「历史预测」页左侧列出历次预测(时间/基于期号/目标状态/推荐特码/大集合/生肖命中),
    右侧只读渲染该期全部预测明细。
  - 命中核对: 切换到该页或点「刷新核对」时, 用本地缓存开奖记录自动比对目标期开奖,
    标注特码/平码/集合/生肖/六维度命中情况(命中球高亮为绿色); 未开奖的目标期标记"待开奖"。
  - 支持「删除选中」「清空历史」。

手工录入开奖 (GUI「✎ 录入开奖」按钮):
  - 当抓取延迟或失败时, 可手工录入当期开奖: 期号 + 7 个号码(6平码+1特码)。
  - 波色按号码固定映射自动着色; 生肖按年度轮换, 取每个号码"最近一次出现"的生肖自动填充。
  - 实时预览解析结果(波色球 + 生肖); 校验号码数量/范围/重复, 同期号可覆盖。
  - 保存后自动并入缓存并切到「历史预测」页重新核对(待开奖 -> 已开奖)。

开奖记录查阅 (GUI「开奖记录」页):
  - 浏览全部历史开奖(默认最新在前), 左侧列表: 期号/开奖时间/平码/特码。
  - 期号筛选(子串匹配, 如输入 2026) + 「⟳ 刷新」重读缓存。
  - 选中某期右侧只读渲染: 6平码+1特码波色球 + 生肖/波色 + 特码统计(和值/大小/奇偶/尾数/头数)。

运行测试:
  python -X utf8 -m unittest discover -s tests -v

输出: 数据概览 + 反推理数学模型清单(含拟合度) + 三组完整预测(6平码+特码) +
      五组特码预测 + 六维度特码属性预测(波色/生肖/尾数/大小/奇偶/头数) +
      特码号码集合预测(8~10颗最可能开出的特码) +
      特码大集合预测(20颗, 单组) +
      特码三生肖预测(3个最可能生肖, 单组) +
      各项回测(命中率/随机基线/lift/标准误/稳定性) + 推荐组 + 科学免责声明。

回测说明:
  - 所有回测均为"留一回测": 对最近 N 期, 每期仅用之前数据预测并比对真实开奖。
  - 随机基线 = 1/类别数(特码 1/49, 波色 1/3, 生肖 1/12 等)。
  - lift = 命中率 - 随机基线, >0 表示优于纯随机。
  - 标准误 = sqrt(p(1-p)/n), 反映命中率估计的不确定度。
  - 稳定性 = 滚动命中率标准差, 越小表示表现越稳定。
  - 由于开奖为独立随机事件, 实测 lift 通常在 0 附近波动, 属正常现象。
