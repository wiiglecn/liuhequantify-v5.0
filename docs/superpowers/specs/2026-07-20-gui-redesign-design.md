# macau_gui.py 界面重设计 — 设计文档

日期: 2026-07-20
状态: 已定稿(用户确认)
范围: `macau_gui.py` 单文件视觉 + 布局改造;预测/数据/存档逻辑零改动

## 1. 背景与目标

当前 GUI 为白底清爽 + 淡红主题,经多轮迭代(深色科技 → 白底 → 3D 球)。本次目标:

1. **专业** — 像量化分析系统,信息层级清晰
2. **科技感** — 精致的视觉语言(渐变、玻璃舱、等宽数字)
3. **美感** — 现代浅色 SaaS 风(Linear/Notion 式)

经可视化对比三轮决策(均有浏览器效果图存档于 `.superpowers/brainstorm/`):

| 决策点 | 选项 | 用户选择 |
|---|---|---|
| 设计方向 | A 深空 HUD / B 暗色金融终端 / C 浅色现代分析台 | **C** |
| 改动范围 | 纯换肤 / 视觉+布局优化 / 全面重构 | **视觉+布局优化** |
| 布局结构 | A 左侧导航 / B 顶部胶囊标签 / C 两级标签 | **A 左侧导航** |

- **侧边导航** 172px 白底:品牌块(红渐变圆角方块「猎」+ 两行标题)→ 三组导航 → 底部状态卡

## 4. 组件改造清单

| 组件 | 现状 | 改造后 |
|---|---|---|
| 卡片 | 白底+灰投影+顶部彩条,直角 | 白底圆角 12px + 柔和投影(PIL 预渲染圆角卡片底图),标题带小图标 |
| 号码球 | PIL 3D 波色球+金环 | **保留渲染管线**,仅投影色适配浅底 |
| 指标磁贴 | 灰底小磁贴 | 大字号 Consolas 数值 + 弱色标签;总览「最近特码」升级为 球+波色+生肖 组合磁贴 |
| 显著性色块 | 直角色块 | 圆角胶囊(语义色不变:绿/灰/琥珀) |
| 模型得分条 | 120px 单色条 | 渐变圆角条,按排名分红/靛/琥珀三系 |
| 按钮 | 直角红/灰 | 圆角 8px,主按钮红+投影,次按钮描边;悬停态保留 |
| 表格 Treeview | 白底 | 白底+浅灰行分隔+选中行浅红底;表头弱色 |
| 录入弹窗 | 白底直角 | 同步令牌(圆角输入框描边、按钮) |
| 免责声明卡 | 灰字 | 虚线边框 + 浅灰底,弱化呈现 |

## 6. 实现策略

- **单文件改造** `macau_gui.py`;预测、数据抓取、存档、核对逻辑零改动
- 圆角卡片/渐变横幅/Logo:PIL 预渲染背景图(九宫格缓存,尺寸变化重渲)贴 Canvas/Label;**无 PIL 时降级**为纯色直角(沿用现有 `_PIL_OK` 分支模式)
- 导航/悬停态:自绘 Frame + `<Enter>/<Leave>/<Button-1>` 绑定
- 主题常量集中替换(现有 `BG_MAIN` 等块),新增渐变/圆角辅助函数
- 倒计时、轮播滚轮路由、队列 `_poll` 机制不变

## 7. 验证

- 人工 UI 核对清单(运行 `run_macau_gui.bat`):
  1. 导航 10 项切换正常,选中/悬停态正确
  2. 10 个页面渲染无样式错乱(球、磁贴、色块、表格)
  3. 开始分析全流程(状态卡、进度、完成后跳总览)
  4. 录入弹窗换肤 + 保存流程正常
  5. 开奖记录/历史预测分栏页刷新、选中恢复正常
  6. 无 PIL 环境降级不报错(模拟 `_PIL_OK=False`)
- 现有 pytest 套件全绿(GUI 无单测,保证不破坏 import 与逻辑模块)

## 8. 明确不做(YAGNI)

- 不重写为 Web/Electron;不引入第三方 GUI 库
- 不改任何预测算法/回测/存档格式
- 不做主题切换(深浅色双主题)、不做响应式/多语言
- 不新增页面或预测功能
