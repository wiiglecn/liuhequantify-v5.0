# V5.8.6 命中率提升研究计划：3肖 / 4肖 / 6肖 / 20码

> 状态：研究与实现路线图，不是命中率保证。所有策略必须先进入影子评估；未通过预先声明的样本外门槛，不得自动替换生产预测。

## 1. 研究目标与随机基线

在本项目当前的 12 生肖候选空间、49 个特码候选空间下，单纯均匀随机选择的理论命中基线为：

| 目标 | 随机基线 | 说明 |
|---|---:|---|
| 3肖 | 3/12 = 25.00% | 命中真实生肖是否落在所选 3 个生肖内 |
| 4肖 | 4/12 = 33.33% | 同上，选择集合扩大 |
| 6肖 | 6/12 = 50.00% | 同上，选择集合扩大 |
| 20码 | 20/49 = 40.82% | 真实特码是否落在所选 20 个号码内 |

不同 K 的命中率不可直接横向比较；K 越大，随机基线本身就越高。所有报告必须与相同 K 的随机基线、旧生产策略和简单基线配对比较。

## 2. 算法候选清单与优先级

### P0：必须先完成的可信度基础

1. **严格 walk-forward / prequential 评估**：预测第 t 期只能使用 t 期之前的数据；所有窗口、权重、阈值和特征都必须在训练/验证历史内选择。
2. **随机零假设模拟**：按真实规则生成大量均匀随机开奖序列，重跑完整策略搜索管线，估计“搜索出看似高命中率”的概率。不能只对最终挑中的模型做单次二项检验。
3. **多重检验控制**：对尝试的模型、窗口、信号、K、特征和超参数使用 Holm/Bonferroni 或 Benjamini–Hochberg；同时报告尝试总数。
4. **时间块 bootstrap / 配对检验**：比较新旧模型在同一开奖期的命中差异；若有序列相关，补充 block bootstrap，不把重叠窗口当作独立实验。
5. **前瞻留出集**：冻结代码、数据清洗、模型候选和决策门槛后，只用之后的新开奖做验证。已查看的历史期不能重新称作“未触碰测试集”。

### P1：低复杂度、适合先验证的模型

- **均匀先验 + Dirichlet / Beta-Binomial 收缩**：对频率计数做平滑，避免短窗口极端热号/冷号。适合作为稳健基线，不代表存在预测性。
- **多时间窗指数衰减**：短、中、长窗（例如 30/60/120/240）以时间衰减汇总频率；衰减参数只能由滚动验证选择。
- **多阶转移与 Markov 信号**：测试一阶转移、滞后特征与历史频率的增量信息。必须与独立随机零假设比较，避免把偶然共现当规律。
- **概率融合 / BMA / 稳健线性排名融合**：用严格 OOS log-loss 或 Brier score 学权重，加入权重收缩与最小有效样本限制；同时报告 Top-K 命中。
- **信号去冗余与增量信息检验**：不只按单信号命中率选信号；测试在基线之上是否真正改善 OOS 排名、log-loss 或命中率。
- **目标 K 专用策略**：3/4/6 肖和 20 码分别训练、分别评估，不假定一套权重适合所有 K。

### P2：需要有足够证据才试验的模型

- **Logistic / multinomial logistic、朴素贝叶斯、浅层树模型、GBDT / CatBoost**：作为有限容量的监督模型候选；通过嵌套时间序列验证比较，不以训练准确率挑选。
- **在线权重更新 / Hedge / EXP3 风格专家组合**：按每个专家过去的 OOS 对数损失或命中表现更新权重；设置探索下限、权重上限和回撤/漂移降级机制。
- **变化点检测 / 漂移感知窗口**：检测近期信号表现是否明显偏离历史；只允许调整窗口或退回简单基线，不允许将随机波动自动解释成“新周期规律”。
- **集合结构与号码对关联**：只有当配对结构在独立 OOS 中持续优于不使用结构的同一模型时才保留。若每期实际只抽出一个特码，生肖间的“共现”特征需要有明确的生成机制，否则很容易制造伪相关。
- **概率校准**：可改善概率可靠性与模型比较，但单调温度缩放不会改变排名，因此不能把校准本身宣称为 Top-K 命中率提升。

### P3：暂不优先

- **深度学习、Transformer、强化学习、遗传算法/粒子群超参搜索**：当前有效样本量有限、结果接近随机时，搜索空间扩大通常先增加过拟合和多重检验风险。只有在 P0/P1/P2 评估框架稳定、数据量和增益证据足够时才考虑。
- **“热号/冷号/遗漏值/连号/生肖周期”等经验规则**：只能作为候选特征进入统一实验，不得以解释听起来合理就直接加权。

## 3. 必须统一报告的指标

每个目标 K 都要报告：样本数、命中数、命中率、理论随机基线、旧模型差值（百分点）、Wilson 区间、配对差值区间、精确二项检验或随机模拟 p 值、经多重检验校正的 q 值、年度/季度切片、代码版本与数据截止日期。

辅助指标包括：log-loss、Brier score、排名质量、模型预测分布熵、信号权重稳定性、预测覆盖/缺失比例、计算耗时。辅助指标不能替代目标命中率和随机基线。

## 4. 预先声明的晋级门槛

一个新策略只有同时满足以下条件，才进入前瞻影子测试：

- 在 3/4/6/20 对应的目标上分别评估，不混淆基线；
- 至少 120/180/300 期多个滚动窗口中，没有系统性落后于旧策略，并且相对同 K 随机基线的增益有正向证据；
- 300 期配对差值区间下界大于 0，且对多重试验校正后仍有支持；
- 按年度/季度拆分时没有明显由单个短区间贡献全部增益；
- 完成数据去重、标签/日期一致性、未来信息泄漏和可复现性审计；
- 冻结实现后，继续进行真正的未来开奖前瞻验证。

即使通过以上历史门槛，也只允许进入影子模式，不自动切换生产策略。任何算法都不能保证未来中奖。

## 6. V5.8.7 实施记录（统计验证层）

已在研究分支增加 `core/statistical_validation_v587.py`，并将统计检验接入 `tools/multi_window_oos_audit.py`：

- 单侧精确二项上尾概率：以每个目标 K 对应的理论随机命中率为零假设。
- Holm 校正：对当前报告中所有目标 K × 窗口检验作为一个检验族，控制家族错误率。
- Benjamini–Hochberg q 值：作为探索性 FDR 指标；窗口重叠且检验相关时需谨慎解释。
- 配对时间块 bootstrap：新旧模型使用相同开奖期命中序列，默认区块长度最多 5 期，报告 95% 差值区间。
- 最大统计量零假设模拟原语：支持按多基线、多候选试验模拟“挑选最高历史成绩”的偏差，并提供 Monte Carlo 校正 p 值函数。

**重要限制：** 当前集成报告会对实际 OOS 命中数执行精确二项检验、Holm/BH 校正及时间块 bootstrap；最大统计量模拟函数尚未在 CI 中对完整自适应策略搜索管线做端到端重放。因此不能把该函数的近似 Bernoulli 模拟称为“完整策略搜索已通过随机零假设审计”。后续需在模拟开奖序列上重跑完整特征生成、模型选择和 K 策略搜索，再将最大统计量校正作为正式晋级依据。

生产策略仍保持不自动切换；历史统计结果只能决定是否进入冻结后的前瞻影子验证。
