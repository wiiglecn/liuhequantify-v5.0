# V5.8.1 Direct Set Prediction

V5.8 upgrades point ranking into direct set construction while retaining strict walk-forward evaluation.

- Existing signal probabilities remain the marginal layer.
- Pair structure uses adjacent historical targets only; it is not treated as same-draw co-occurrence.
- Set construction uses marginal score plus optional pair affinity and signal-space diversity.
- K-specific policies are independently fitted for 3/4/6/20.
- Horizon and structural lambdas are selected on an inner validation tail before the target.
- lambda=0 candidates allow automatic fallback to marginal-only prediction.
- The final 60 folds are frozen and never used for policy selection.

Research boundary: this is historical OOS research only; it does not establish future predictability.
