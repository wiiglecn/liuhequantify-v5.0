# V5.8.4 Residual Feature Discovery

V5.8.3 found no statistically accepted residual contribution from the existing signal families. V5.8.4 therefore changes the search object: instead of re-blending the same signals, it constructs orthogonal meta-features from the probability surface.

Candidates:
- entropy mean/std
- top-1 score gap mean/std
- cross-signal disagreement
- rank dispersion
- recent surprise
- top-3 concentration mean/std

Selection is point-in-time. The K-specific baseline is fitted from history before each target fold. Feature selection uses an earlier OOS segment and validates on a later segment. BH/Bonferroni are applied to the validation feature family. Final holdout remains untouched.

Important: these are historical research diagnostics only; no future predictability claim is made.
